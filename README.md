# 个人绘图法典

个人绘图法典是一个独立运行的本地提示词图鉴，支持 Windows 本机和 Docker Compose 部署。它从图片原文件读取生图参数，同一组画师词合并成一张可搜索的画师串卡片。

## Windows 本机

启动后访问 [个人绘图法典](http://127.0.0.1:18770/)。

1. 双击 **启动个人绘图法典.bat**。在另一台 Windows 电脑首次运行时，启动器会用 Python 3.12 安装图像读取依赖。
2. 点 **图片目录** 核对原图目录，也可以填现有缩略图与预览目录。默认尝试读取相邻「QQ爬楼bot」的本机原图目录。
3. 点 **扫描新图**。第一次建立索引，后续扫描按路径、文件大小与修改时间跳过未变文件，图片内容按 SHA-256 去重。
4. 在 **图鉴** 中搜提示词、筛选 NAI 4.5 或 NAI 5，或查看原图。多个搜索条件用逗号分隔，词前加减号可排除。可在结果数旁选择每页图片数量，在列表顶部或底部翻页，也可以输入页码跳转。
5. 在 **画师串** 中按画师名查找，下滑会自动加载更多缩略图。每组显示一张封面，详情可查看封面对应的提示词和生图参数。点击 **挑选封面** 可以从同组中选图。同一模型版本的画师串会按入典顺序依次获得默认编号。手工设定的名称、封面、收藏和笔记保存在法典数据库。
6. 在图片或画师串详情可移入 **回收站**，随时恢复。删除画师串后，同组图片仍可从图鉴查看。删除图片只移除法典里的展示，原图和缩略图仍存放在原目录。

画师串来自 NovelAI 原图的主正向提示词。当前自动识别带 artist: 前缀的名称，并保留相对顺序、数值与括号权重。同串的模型版本可在详情内切换。初选封面优先使用可读、少参考图干预、尺寸较大的图片，手动挑选后固定。

法典以只读方式访问图片。列表使用 832 × 1216 的竖版缩略图，保持整张画面。法典优先使用现有清晰预览，在内存中生成列表缩略图。点左侧导航边缘的箭头可完全隐藏导航，再点窗口左边缘的把手即可展开。图鉴和画师串会默认使用窗口的可用宽度，缩略图列数随窗口大小和浏览器缩放自动调整。侧栏状态保存在当前浏览器。目录暂不可用时可以继续查看已入典的文字。拾集停机时，法典仍可读取原图与缓存。群聊里单独发的提示词、拾集收藏和隐藏状态保存在拾集库中。

法典数据库保存索引、手动名称、收藏、笔记、回收站和画师串编号。Windows 默认位于 `.runtime/catalog.sqlite3`。

## NAS 或 Linux Docker

需要 Docker Compose v2。将项目目录放到计划存放程序与数据库的磁盘。准备图片目录的绝对路径。原图、预览和缩略图都可以直接使用已有目录。

1. 创建本机配置与独立密码文件。

   ```sh
   mkdir -p data/empty-previews data/empty-thumbnails private
   cp .env.example .env
   (umask 077; openssl rand -hex 24 > private/password)
   ```

2. 编辑 `.env`，填写 `GRIMOIRE_ORIGINALS`。可以同时填写 `GRIMOIRE_PREVIEWS` 和 `GRIMOIRE_THUMBNAILS`。这三处以只读方式挂载。原图位于可拆卸磁盘时，可在该目录设置标记文件，再在 `GRIMOIRE_ORIGINALS_MARKER` 填写文件名。
3. 在可信局域网访问时，将 `GRIMOIRE_IP` 设为 NAS 的内网 IP，并同步修改 `GRIMOIRE_PUBLIC_URL`。更换宿主机端口时，同步修改 `GRIMOIRE_PORT` 与访问地址里的端口。需要远程访问时使用 HTTPS 反向代理。
4. 启动后用用户名 `grimoire` 和 `private/password` 里的密码登录。

   ```sh
   docker compose up -d --build
   docker compose ps
   ```

5. 在网页点击 **扫描新图**。首次读取耗时取决于图库大小，进度会显示在页面。Docker 数据库位于 `data/catalog.sqlite3`。备份前可以先停止法典服务。

Docker 服务端根据部署配置锁定共享目录。仓库包含程序、文档和示例配置，个人图库、索引和登录凭据由各自的部署实例保存。

## 代码来源

`grimoire/legacy_metadata.py` 与 `grimoire/generation_evidence.py` 沿用绘图拾集内置的离线元数据读取与校验规则。解压缩图像元数据的上限为 4 MiB。法典本身可以独立使用。
